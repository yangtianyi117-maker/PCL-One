# PCL Pro 手机版 · 使用说明

## 这是什么

PCL Pro 的手机端联机助手。电脑上用 PCL Pro 建房，手机在同一个 Wi-Fi 下打开它，
自动找到房间，复制地址，进 Minecraft Bedrock 服务器。

**地球服（默认主服）**：打开 App → 大厅「地球服」卡片 →「进入」，手机走 Bedrock
`124.221.231.213:19132`，和 PC Java `124.221.231.213:25566` 是同一张 1:1000 地球地图。
「地球指南」按钮会**在 App 内打开离线指南**（`assets/earth.html`），没网也能看规则与坐标；
想用浏览器打开时再走公网地址。

> 它不是 Java 版启动器：Minecraft Java 版仍然要在电脑上由 PCL Pro 启动。

## 安装

- 方式一：把 `PCLProMobile-2.1.0.apk` 发到手机，点开安装（需要允许"安装未知来源应用"）。
- 方式二：手机用数据线连电脑，打开 USB 调试，双击 `安装到手机.bat`。

要求：Android 7.0 及以上。

## 第一次使用

1. 电脑打开 PCL Pro，进入「联机」页，创建房间；
2. 确认电脑已经启动 Paper + Geyser（手机 Bedrock 通道，端口 19132）；
3. 手机连接**同一个 Wi-Fi**（不要开"AP 隔离"）；
4. 打开 PCL Pro 手机版 → 大厅 → 「扫描局域网」；
5. 列表里出现房间后，点「进入」：地址会自动复制，Minecraft 会被拉起；
6. 在 Minecraft 里：游戏 → 服务器 → 添加服务器 → 粘贴地址 → 进入。

## 扫不到电脑怎么办

按顺序检查：

1. 手机和电脑是不是同一个 Wi-Fi、同一网段（设置页能看到"本机"和"扫描网段"）；
2. 电脑防火墙是否放行 UDP 19132（Geyser 的 RakNet 端口）；
3. 路由器是否开了 AP 隔离 / 访客网络；
4. 用「手动添加」直接填电脑 IP，例如 `192.168.1.5`，端口 `19132`；
5. 电脑上 `ipconfig` 看一下 IPv4 地址，手机浏览器能打开 `http://电脑IP:19132` 不代表 UDP 通，以 App 扫描结果为准。

> 电脑如果装了 VPN / 虚拟网卡，手机可能扫到多个网段，扫描会稍慢，属正常。

## 房间号与邀请

- 在 PCL Pro 建房后拿到形如 `U/R4YN-L7KP-A7Z2-JL9B` 的房间号；
- 在「房间」页填入房间号和服务器地址并保存；
- 点「复制邀请」会生成一段可以直接发给朋友的文字（房间号 + 地址 + 进服步骤）。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| INTERNET | 发送 Bedrock UDP 探测包 |
| ACCESS_NETWORK_STATE / ACCESS_WIFI_STATE | 判断 Wi-Fi 状态、读取本机地址 |
| CHANGE_WIFI_MULTICAST_STATE | 接收 Bedrock 局域网广播（224.0.2.60） |

App 不联网上传任何数据，没有广告、没有统计 SDK。

## 常见问题

**Q：为什么显示"人数未知"？**
有些服务器（或代理）不返回人数，只能显示 `-- / --`。

**Q：延迟为什么是 0 ms？**
局域网广播（224.0.2.60）不带延迟测量，显示 0；UDP 扫描到的服务器是真实往返延迟。

**Q：能连 Java 版服务器吗？**
这个版本只走 Bedrock 协议（Geyser 端口）。Java 版请让电脑上的 PCL Pro 连接。

**Q：会取代 PCL Pro 吗？**
不会。它是 PCL Pro 的配套工具，负责手机上"找到房间、进入房间"这一段。
