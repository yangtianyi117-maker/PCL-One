# 世界规则（v1 默认值）

> 目标是「地理即关卡」：距离、边界、领地、战争都由地图决定，而不是由插件菜单决定。
> 以下为默认值，上线前可按 `server/config/towny-overrides.md` 调整。

## 1. 身份与登录

- Java：`online-mode=false` + AuthMe（注册/登录），兼容 PCL 离线账号；有正版账号的玩家可绑定。
- Bedrock：Geyser + Floodgate，昵称前缀 `.`，与 Java 玩家同权限。
- 禁止小号刷地：同一 IP 注册数量限制；管理员可封禁。

## 2. 领地（Towny）

| 项 | 默认 | 说明 |
|---|---|---|
| 建镇费用 | 1,000 | 防止随手圈地 |
| 建国费用 | 5,000 | 国家是长期承诺 |
| 每格 claim 价格 | 10 | 按面积付费 |
| 单镇 claim 上限 | 256 格 | 约 16×16 区块 |
| 每日税收 | 10/人 | 用于国家金库 |
| 战争开关 | 开 | 见 §4 |
| 出生点保护 | 32 格 | 禁止破坏 |

## 3. 经济

- 货币：金锭（EssentialsX + Vault）。
- 初始余额：100。
- 收入：砍树/挖矿/交易由玩家自行完成；不设系统商店收购，避免通胀。
- 不卖资源、不卖领地、不卖战斗力。

## 4. 战争

- 宣战需要国家等级 ≥ 1、战争金 2,000。
- 战争持续时间 48 小时；可谈判停战。
- 只能攻击敌对国家已 claim 的区块；出生点、传送点、公共设施免战。
- 禁止利用 bug（卡墙、复制、刷物品）；违者回滚 + 封禁。
- 战争期间允许拆敌国建筑，但禁止破坏服务器公共设施。

## 5. 移动

- 允许 `/spawn`；默认禁用 `/tpa`、`/home` 跨洲传送（距离是成本）。
- 允许床、船、矿车、冰道、下界（下界坐标 1:8，作为长途通道，不额外限制）。
- 鞘翅允许；后续根据平衡调整。

## 6. 禁止

- 外挂、透视、自动挖矿、飞行（除鞘翅/创造）。
- 复制物品、利用区块加载漏洞。
- 恶意卡服（大量实体/红石时钟）。
- 现实政治/仇恨言论；国家名不得使用真实国家名冒充官方。
- 未经许可录制并公开他人基地坐标。

## 7. 处罚

| 行为 | 首次 | 再次 |
|---|---|---|
| 破坏出生点/公共设施 | 回滚 + 7 天 | 永久 |
| 外挂 | 永久 | — |
| 刷物品/复制 | 回滚 + 30 天 | 永久 |
| 恶意卡服 | 警告 + 回滚 | 7 天 |

## 8. 管理

- 管理员不参与国家战争；不滥用 `/give`。
- 所有管理操作留痕（CoreProtect + 日志）。
- 规则变更提前 7 天公告；涉及战争/领地的变更不追溯。
