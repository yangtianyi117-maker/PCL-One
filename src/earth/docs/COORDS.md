## 2. 坐标公式

```text
x = lon / 179 * 19968
z = 192 - (ln(tan(pi/4 + lat/2)) / ln(tan(pi/4 + 80°/2))) * 15552
```

- `lat` 北纬为正，`lon` 东经为正；
- 纬度 ±80° 对应 Z 边界；经度 ±179° 对应 X 边界；
- 反解：`lon = x / 19968 * 179`；`lat = 2*atan(exp(m)) - pi/2`，其中 `m = (192 - z) / 15552 * ln(tan(pi/4 + 40°))`。

## 4. 出生点

- 坐标：`(3233, 64, -4826)`（伊斯坦布尔，博斯普鲁斯海峡西岸）。
- 命令：
  ```text
  /execute in minecraft:overworld run setworldspawn 3233 64 -4826
  /gamerule spawnRadius 0
  ```
- 出生平台：64×64 石台 + 四个方向指示牌（欧洲 / 亚洲 / 地中海 / 黑海），预留扩建空间。
- `spawn-protection=32`，禁止在出生点破坏；`/spawn` 由 EssentialsX 提供。

## 5. 世界边界

原版 `/worldborder` 只能是正方形，这张地图是矩形，必须用 ChunkyBorder：

```text
/chunky world Earth1000
/chunky shape rectangle
/chunky corners -19968 -15360 19968 15744
/chunky border add
```

验收：从边界内向外走会被拦截；`/chunky border` 输出的范围与上表一致。
