PCL Earth · 地球服

一张真实地球地图，PC Java 与手机 Bedrock 在同一个世界。出生在伊斯坦布尔，去你现实中的家乡建城、建国、打仗。

1:1000 单世界 · 不重置 Java + Bedrock

怎么进

PC：打开 PCL One →「进入地球」；安装过地球扩展的话会自动进服。

手机：安装 Minecraft 基岩版，添加服务器 124.221.231.213，端口 19132；或在 PCL Pro 手机版大厅点「地球服 → 进入」。

地址：Java 124.221.231.213:25566 · Bedrock 124.221.231.213:19132

出生点与坐标

出生点：伊斯坦布尔，博斯普鲁斯海峡西岸，约 3233, 64, -4826。

地图是 Web Mercator 投影：x = 经度 / 179 × 19968， z = 192 − (Mercator(纬度) / Mercator(80°)) × 15552。

参考：北京约 12986, -4664；纽约约 -8256, -4782；开罗约 3484, -3320；里约约 -4816, 2815；悉尼约 16868, 4207。

规则摘要

  • 建镇 1,000；建国 5,000；每格领地 10；单镇上限 256 格。
  • 允许战争：宣战需战争金 2,000，持续 48 小时；出生点/公共设施免战。
  • 允许 /spawn；默认禁用跨洲 /tpa 与 /home。
  • 禁止外挂、透视、复制物品、恶意卡服、破坏出生点。

边界

X ∈ [−19968, 19968]，Z ∈ [−15360, 15744]；矩形边界由 ChunkyBorder 维护，走出边界会被拦回。
